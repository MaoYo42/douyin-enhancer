# 网页抖音增强 · 智能跳广告

![version](https://img.shields.io/badge/version-5.19-blue)
![license](https://img.shields.io/badge/license-GPL--3.0-green)
![platform](https://img.shields.io/badge/platform-Chrome%20%2F%20Edge%20%2F%20Firefox-lightgrey)

> 网页版抖音**没有**「跳过广告」按钮，只能一条条往下划。
> 这个脚本替你看：认出广告角标、认出带货标签、认出商品链接，然后自动划走。

---

## 🎯 核心功能：智能跳广告

判断广告不看 class 名（抖音的 class 是哈希化的，随时会变），而是看**三类稳定信号 + 几何位置**：

| 信号 | 说明 | 判定 |
|---|---|---|
| `广告` 角标 | 抖音官方的广告标识（含 `svg[viewBox="0 0 30 16"]` 图标与文字徽标） | 命中即跳 |
| `购物·xxx` 标签 | 带货视频左下角的商品标签，按**文字前缀**识别：购物 / 商品 / 橱窗 / 同款 / 购买 / 小黄车 / 去购买 / 进店 | 命中即跳 |
| 商品链接 | 指向 `haohuo` / `jinritemai` / `/product/` / `/goods/` 的链接 | 命中即跳 |

### 三重防误杀

光「认得出」不够，误杀比漏判更烦人。所以还叠了三层保护：

**① 只认视口内的角标**

抖音会把上下相邻的视频都留在 DOM 里，它们的角标也一直在。所以角标必须满足「中心点落在视口内」：

```js
const inRegion = (r) => {
  const cx = r.left + r.width / 2;
  const cy = r.top + r.height / 2;
  return cx > 0 && cx < vw * 0.95 && cy > 2 && cy < vh - 2;
};
```

- 上一个视频的残留角标 → `y < 0` → 排除
- 下一个视频的预加载角标 → `y > vh` → 排除

> 这一条是踩坑换来的：早期版本用 `<video>` 元素的矩形做基准，但竖屏沉浸模式下 `<video>` 会被挪到视口外（实测 `rect.top = -1151`），结果把上一个视频的角标当成当前的，**广告放过了，下一个正常视频被跳了**。

**② 连续 2 帧确认**

单个 300ms 周期命中不算数，要连续两次都命中才执行跳过，约 600ms。

**③ 跳过只补按一次方向键**

原来的确认逻辑每 500ms 检查一次，没切换就补按一次，最多 5 次。抖音切换视频经常超过 500ms，于是**一次跳过连跳两条**。现在改为：300ms 只读轮询、2 秒后才补按、且全程只补一次、5 秒放弃。

### 效果

```
【广告检测】命中「购物 | 视频同款」→ shop-tag (256x30, 16px, 位置 16,953)
【广告检测】命中[shop-tag] (1/2)，等待确认
【广告检测】确认广告[shop-tag]，执行跳过
跳过视频，原因：⏭️ 自动跳过: 广告视频(shop-tag)
```

## 其他功能

| 功能 | 说明 |
|---|---|
| 跳直播 | 识别「进入直播间」并自动跳过 |
| 内容屏蔽 | 关键词 / 作者声明 / 平台提示（含 AI 生成内容）多维度屏蔽，可自动按 R 不感兴趣 |
| 最高清 | 自动切到最高分辨率 |
| 分辨率筛选 | 只保留指定清晰度 |
| 极速模式 | 固定秒数或随机区间自动切换 |
| 统计面板 | 刷视频数量 / 时长 / 年度热力图，支持导入导出 |
| 直播净化 | 屏蔽送礼信息、福袋口令、礼物特效 |

另有独立脚本 **`douyin-keepalive.user.js`**：防止「长时间无操作，已暂停播放」，切到后台时保持音频继续播放。

## 安装

1. 先装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox 均可）
2. 点下面的链接安装：

| 脚本 | 安装 |
|---|---|
| 网页抖音增强（含跳广告） | [安装](https://raw.githubusercontent.com/MaoYo42/douyin-enhancer/main/douyin-enhancer.user.js) |
| 抖音后台音频保护（可选） | [安装](https://raw.githubusercontent.com/MaoYo42/douyin-enhancer/main/douyin-keepalive.user.js) |

装完打开 [douyin.com](https://www.douyin.com)，播放器右下角工具栏会出现一排开关，确认「跳广告」是开启状态即可。

## 使用与调试

工具栏按钮：`设置` · `跳直播` · `跳广告` · `内容屏蔽` · `最高清` · `分辨率筛选` · `极速模式`

想看广告检测到底干了什么，按 `F12` 打开 Console，刷几个视频，会看到：

- `【广告检测】命中「...」→ shop-tag` —— 认出来了
- `【广告检测·诊断】含关键词但未判定：...` —— 找到了疑似标签但被某个条件排除，日志会标明是尺寸、字号还是位置问题

把诊断日志贴到 [Issues](https://github.com/MaoYo42/douyin-enhancer/issues)，通常一次就能定位。

## 已知限制

- **抖音改版会失效。** 判定逻辑基于 DOM 文字与几何位置，改版后可能需要调整。
- **极速模式会干扰测试。** 每 N 秒强制切视频，会和广告跳过抢时机，调试时建议先关掉。
- **DevTools 建议独立窗口。** 停靠右侧会让页面视口收窄，影响几何判定。
- AI 智能筛选（视觉模型判断内容偏好）在当前版本**已停用**，代码保留但入口移除。
